🔹 Terraform is a tool for building,changing and versioning Infra safely and cleanly. 
IT is compatible in many cloud and servers services.

🔹 Steps in Terraform: 
	Command  				Purpose
	🔹tm init		Initialize Terraform project (reads .tf file created by user)
	🔹tm plan		Preview changes (it shows what changes will occur)
	🔹tm apply		Create/update infrastructure (apply to make change)
	🔹tm destroy		Delete infrastructure
	🔹tm fmt		Format your .tf files neatly
	🔹tm validate		Check syntax correctness
